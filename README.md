# Customer Shopping Behavior Analysis

An end-to-end data analytics project focused on understanding customer shopping patterns, purchasing behavior, customer segmentation, and revenue trends using **Python, SQL, and Power BI**.

## Project Overview

This project analyzes customer shopping behavior to identify meaningful patterns in purchasing decisions and generate business insights. It uses data analysis, SQL-based business queries, and interactive dashboard visualization to explore customer preferences and spending trends.

The objective is to transform raw customer shopping data into actionable insights that can support business decision-making.

## Tech Stack

- **Python:** Data cleaning, preprocessing, exploratory data analysis (EDA)
- **Pandas & NumPy:** Data manipulation and analysis
- **Matplotlib & Seaborn:** Data visualization
- **SQL:** Business queries and data analysis
- **Power BI:** Interactive dashboard and reporting
- **Jupyter Notebook:** Analysis and experimentation

## Project Workflow

1. **Data Understanding:** Explored the customer shopping dataset and examined its structure.
2. **Data Cleaning:** Used Python to prepare and preprocess the dataset for analysis.
3. **Exploratory Data Analysis:** Analyzed customer demographics, purchasing patterns, discounts, product preferences, and spending behavior.
4. **SQL Analysis:** Developed business-focused SQL queries to answer questions related to customer purchases, revenue, subscriptions, and customer segments.
5. **Dashboard Development:** Used Power BI to create an interactive dashboard for presenting analytical findings.
6. **Business Insights:** Interpreted the results to understand customer behavior and identify potential business opportunities.

## Key Business Questions

The analysis explores questions such as:

- How does purchasing behavior differ across customer demographics?
- Which products receive the highest ratings?
- How do discounts influence customer spending?
- How do subscribers and non-subscribers differ in purchasing behavior?
- Which customer segments contribute to revenue?
- What patterns can be identified among repeat customers?
- How does shipping type relate to customer purchasing behavior?

## How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/hackinghobbit01/Customer-Behavior-Analysis.git
```

### 2. Navigate to the project directory

```bash
cd Customer-Behavior-Analysis
```

### 3. Install Python dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter sqlalchemy pymysql
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the cells.

### 5. Execute SQL Queries

Open `customer_behavior_sql_queries.sql` in a database environment compatible with the SQL syntax used in the script. Configure the database and table using the provided dataset and queries.

### 6. Explore the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` using Power BI Desktop to explore the visualizations and customer behavior insights.
